# mcp (MCP 버전 안내)

MCP 버전 사용자가 MCP 를 지원하는 프로그램 대화창에서 해설을 만들게 안내한다. 기준: `../Backend/src/main/java/com/mathmakesmoney/backend/mcp/CLAUDE.md`

## 흐름 (웹이 맡는 곳)

1. 업로드로 작업 생성 (`mode=mcp`)
2. 작업 상세에 대화창에 붙일 문장과 복사 버튼: 실제 작업 제목으로 요청하고 작업 주소 `/jobs/{id}`를 함께 넣어 동일 제목을 구분한다
3. 사용자 모델이 도구를 부르며 진행 -> 웹 작업 상세가 저장된 단계만큼 채워진다
4. 도구가 돌려준 웹 결과 링크로 들어와 확인·수정·HWP 다운로드 (`src/features/result/`)

## 연결 안내 화면

- Claude와 Codex 모두 연결 + 실행 한 줄 명령을 제공한다. Nginx 공용 admin 인증 제거는 사용자 결정(2026-10-01)이다. 현재 작업은 공용이며 사용자별 접근 제한은 없다. 로그인 구현은 보류하고 기본 사용자 1의 작업으로 요청한다(2026-10-01 사용자 결정). 사용자 번호는 인증·소유권 검증을 뜻하지 않는다.
- 실행 명령은 풀이담 MCP 도구만 자동 승인한다. Claude는 --allowedTools mcp__pulidam__*, Codex는 mcp_servers.pulidam.default_tools_approval_mode=approve를 사용한다. 화면은 사용자 실제 실행에서 절반 풀이 약 3분(2026-10-01)을 근거로 약 5~15분을 안내하며 문항 수·AI·검증·파일 생성에 따라 더 걸릴 수 있다고 명시한다.
- 연결·실행 명령은 현재 사이트 origin의 `/mcp` 주소를 사용하므로 배포 도메인으로 자동 바뀐다. 서버도 같은 `/mcp` 경로를 제공해야 한다
- 사용자 문장은 풀이담 도구라고 부르고 CLI 연결 이름은 `pulidam`이다. Claude Code 로컬 CLI에서 한글 서버 이름은 거절됨을 확인했다(2026-10-01). 공식 연결 문법: https://code.claude.com/docs/en/mcp
- 왼쪽 Claude·오른쪽 Codex 카드로 AI를 선택하며 기본은 Codex다. 터미널 선택 UI는 없고 OS에 따라 PowerShell 또는 맥·리눅스 셸 명령을 자동 생성한다. 제목·수정 요청은 선택한 셸의 작은따옴표 규칙으로 감싸 `$`, 백틱, 따옴표가 실행되지 않게 한다. 이미 연결돼 있으면 add 오류 뒤 `;`로 실행을 이어간다
- localhost 안내는 로컬 주소일 때만 보인다. 원격 서버 인증 방식은 별도 배포 설정이 필요하다
- 웹 버튼으로 터미널을 열어 실행하는 건 브라우저가 막는다. 하려면 PC 마다 URL 프로토콜 처리기를 설치해야 한다 (안 함)
- Claude Desktop, claude.ai, ChatGPT 는 내 컴퓨터(localhost)에 접속할 수 없어 로컬 PoC 에서는 못 쓴다고 알린다
- 원격 서버 주소·인증(OAuth) 방식은 미정. 정해지면 여기 적는다

## 알려 줄 것 (PoC 근거)

- 오래 걸리고 사용자 구독 한도를 쓴다: 모평 30문항 41분, 한 세트에 구독 5시간 한도 약 14%. Pro 요금제로 한 세트가 되는지는 아직 모름
- 중간에 끊겨도 문항 단위로 저장돼 같은 문장으로 이어서 할 수 있다
- 결과 품질이 사용자 모델·요금제에 따라 다르다. 결과마다 기록된 모델 이름(`model`)을 결과 화면에 보여 준다

## 금지

- 웹이 사용자의 Claude·ChatGPT 구독 로그인이나 토큰을 받지 않는다 (약관)

## 결과 화면에 더할 것 (MCP 작업만, `src/features/result/`)

- 독립 검증이 풀이와 같은 대화에서 나와 API 버전보다 검증 신뢰도가 낮다고 안내 (PoC 에서 다시 저장할 때 독립 답이 풀이를 따라 바뀜)
- 처음 제출 후 고친 횟수 (예: 처음 제출 후 2번 고침). PoC 첫 묶음이 3/10 이었다가 서버 검토 표시를 보고 고쳐졌다. 필드 `revisionCount` (API 버전은 0)
