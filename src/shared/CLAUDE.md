# shared

여러 기능 폴더가 같이 쓰는 최소한만 둔다. 한 기능만 쓰는 것은 그 기능 폴더로 옮긴다.

## API 호출

- 모든 요청은 `/api` 아래. 인증은 account 에서 정한 방식을 따른다 (세션 쿠키면 `credentials: 'include'`)
- 에러 처리 공통
  - 400: 백엔드가 주는 사유를 그대로 보여 준다 (형식 불명, 암호 걸린 파일, 배포용 HWP 등)
  - 401: 로그인 화면으로
  - 402: 크레딧 부족 안내 -> 요금제·크레딧 화면 링크
  - 404: 없는 작업 (다른 회원 작업도 404)
- 응답 타입은 백엔드 문서 JSON 모양 그대로 TypeScript 타입으로 둔다. 필드 이름을 바꾸지 않는다

## 수식 표시 (<<EQ>>)

- 본문 속 수식은 `<<EQ>>한글 수식 스크립트<</EQ>>` 로 온다 (`../Backend/.../shared/CLAUDE.md`)
- 스크립트 예: `{1} over {2}`, `x ^{2}`, `LEFT ( RIGHT )`, `rm A`. LaTeX 가 아니다
- 문장을 글자 조각과 수식 조각으로 나누고(`equation.ts`), 수식 조각은 `hwpeq.ts` 의 `toLatex` 로 LaTeX 로 바꾼 뒤 KaTeX 로 그린다 (`RichText.tsx`). 스크립트 원문을 KaTeX 에 그대로 넣지 않는다
- 변환이나 그리기가 실패하면(KaTeX 오류 표시 포함) 스크립트 원문을 고정폭 칩으로 보여 준다. 칩에는 `data-eq-fallback` 이 붙는다
- 변환 규칙: `over` 는 양옆 한 덩어리(그룹이나 토큰)를 묶는다. 세 글자 이상 단어는 대소문자 무시(OVER, over), 그리스 문자는 구분(pi, PI). 모르는 단어는 글자 그대로, 한글과 따옴표 글은 `\text{}`
- 변환 테스트는 실제 작업과 PoC 결과 JSON 에서 뽑은 스크립트로 만든다 (`hwpeq.test.ts`). 새로 깨지는 스크립트가 나오면 테스트부터 추가한다
- 근거: 작업 1, PoC 결과 JSON 의 스크립트 2785개를 모두 KaTeX 오류 없이 그렸다 (2026-09-29)
- 수정 화면에서는 `<<EQ>>` 표시를 지우거나 망가뜨리지 않게 원문 그대로 편집한다

### 나누기 테스트 (순수 함수, 먼저 테스트)

- `가 <<EQ>>x ^{2}<</EQ>> 이다` -> [글자 `가 `, 수식 `x ^{2}`, 글자 ` 이다`]
- 수식 없음 -> [글자 하나]
- 닫는 표시가 없으면 나머지를 글자로 둔다 (깨진 입력에 화면이 죽지 않게)

## 그림

- 문항 그림 `figures` 는 URL 목록 (`/api/jobs/{id}/figures/{file}`). 로그인 쿠키가 필요하므로 같은 도메인에서 부른다
- stem 속 `[그림]` 은 그림 자리 표시다. 그 위치에 figures 를 차례로 그리면 원본과 같은 배치가 된다
- `[그림 1]`, `[그림 2]` 처럼 번호가 붙은 것은 시험지 원문 글자라 그대로 글자로 둔다. 우리 표시는 `[그림]`, `[그림:id]`, `[그림파일:경로]` 셋뿐
